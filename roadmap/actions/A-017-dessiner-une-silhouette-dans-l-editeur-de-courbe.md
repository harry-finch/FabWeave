R-020 fait le 17/11/2026, éditeur jamais ouvert par l'agent (navigateur indisponible). Version web : cd ui && npm run wasm && npm run dev, http://localhost:5175 ; ou l'application macOS après npm run desktop. Modèle « Vase à silhouette libre » (Vases et luminaires), puis le vase à ondulations (silhouette facultative). Gestes : glisser des points, cliquer sur le trait pour en ajouter, double-cliquer pour en retirer, flèches et Suppr sur un point, saisie chiffrée du rayon et de la hauteur, Galerie…, ↺, ⌘Z après un glisser ; thème clair et sombre ; pouces. Observer : la vue 3D suit la courbe, le cadre et les échelles se lisent, une valeur saisie hors bornes est soulignée (export bloqué). Répondre : prise en main jugée bonne, ou gestes à revoir.
