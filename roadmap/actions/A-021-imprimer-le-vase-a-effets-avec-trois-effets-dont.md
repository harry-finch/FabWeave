R-021 fait le 17/11/2026, jamais regardé dans l'interface par l'agent. Version web (cd ui && npm run wasm && npm run dev) ou application macOS. Modèle « Vase à effets » : parcourir les sept effets dans la vue 3D, puis imprimer au moins trois vases (MK4S ou CORE One, PLA), dont un en dentelle (essayer Vitesse crête et Recul du pied sous Avancé). Observer : texture conforme à la vue, tenue de la dentelle (arches qui ne s'affaissent pas, pieds soudés), messages du garde-buse. Répondre : effets validés, réglages qui marchent, défauts.
