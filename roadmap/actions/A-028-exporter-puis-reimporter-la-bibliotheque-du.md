Version web (cd ui && npm run wasm && npm run dev) ou application macOS, avec quelques modèles personnels (« Mes modèles ») et profils personnels. Fichier › Exporter ma bibliothèque (fichier bibliotheque.fabweave-library.json) ; vider les données du site (outils du navigateur, ou autre poste) ; Fichier › Importer une bibliothèque… (ou déposer le fichier). Observer : mêmes modèles et profils, message du nombre importé ; réimporter une seconde fois : tout est « déjà présent ». Répondre : aller-retour réussi ou pertes.
